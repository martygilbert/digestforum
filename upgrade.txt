=== 4.5 Onwards ===

This file has been replaced by UPGRADING.md. See MDL-81125 for further information.

===
This files describes API changes in /mod/digestforum/*,
information provided here is intended especially for developers.

=== 4.5 ===

* Final deprecation of digestforum_update_subscriptions_button().

=== 4.4 ===

* The mod_digestforum_get_digestforum_discussions_paginated web service has been removed from core.

=== 4.3 ===

* The digestforum_print_discussion_header function has been deprecated and will not be replaced.

=== 4.1 ===

* The following code, previously used (exclusively) by upgrade steps is not available anymore
  because of the upgrade cleanup performed for this version. See MDL-71747 for more info:
    - \mod_digestforum\task\refresh_digestforum_post_counts adhoc task.

=== 4.0 ===

* The digestforum_count_replies() function has been removed from core.
* The mod_digestforum_get_digestforum_discussion_posts web service has been removed from core.
* Final deprecations of the following functions:
    * digestforum_make_mail_text
    * digestforum_make_mail_html
    * digestforum_make_mail_post
    * digestforum_cron_minimise_user_record
    * digestforum_cron
    * digestforum_print_discussion
    * digestforum_post_nesting_cache
    * digestforum_should_start_post_nesting
    * digestforum_should_end_post_nesting
    * digestforum_print_post_start
    * digestforum_print_post_end
    * digestforum_print_post
    * digestforum_print_posts_flat
    * digestforum_print_posts_threaded
    * digestforum_print_posts_nested
    * digestforum_print_latest_discussions
    * digestforum_get_user_grades
* The method digestforum_update_subscriptions_button() has been deprecated as it is no longer used.
  The 'Manage subscribers' button has been replaced with tertiary navigation.

=== 3.11 ===

* The get_digestforum_discussions_paginated web service has been deprecated in favour of get_digestforum_discussions.
* The digestforum post exporter now includes a "timemodified" field for each post, which is included in several WS methods:
    * mod_digestforum_get_discussion_posts
    * get_discussion_posts_by_userid
    * get_discussion_post
    * add_discussion_post

=== 3.10 ===

* Changes in external function mod_digestforum_external::get_discussion_posts_by_userid
  Now returns the posts of a given user checking the current user capabilities ($USER, the user who is requesting the posts).
  Previously, it returned the posts checking the capabilities of the user that created the posts.

=== 3.8 ===

* The following functions have been finally deprecated and can not be used anymore:
    * digestforum_scale_used()
* In order for the digestforum summary report to calculate word count and character count data, those details are now stored
    for each post in the database when posts are created or updated. For posts that existed prior to a Moodle 3.8 upgrade, these
    are calculated by the refresh_digestforum_post_counts ad-hoc task in chunks of 5000 posts by default. Site admins are able to modify this
    default, by setting $CFG->digestforumpostcountchunksize to the required integer value.

=== 3.7 ===
  * Changed the digestforum discussion rendering to use templates rather than print functions.
  * Added new digestforum entities, factories, exporters, renderers, and vaults in the local namespace to better encapsulate the digestforum data.
  * Deprecated all of the digestforum_print_* functions in lib.php.
  * The digestforum_print_latest_discussions function has been deprecated and will not be replaced.
  * The get_digestforum_discussion_posts web service has been deprecated in favour of get_discussion_posts.
  * The digestforum_count_replies function has been deprecated in favour of get_reply_count_for_post_id_in_discussion_id in
    the Post vault.
  * External function get_digestforums_by_courses now returns two additional fields "duedate" and "cutoffdate" containing the due date and the cutoff date for posting to the digestforums respectively.
  * External function get_digestforum_discussion_posts now returns an additional field "tags" returning the post tags.
  * New external function mod_digestforum_external::get_digestforum_discussions returns a list of digestforum discussions optionally sorted and paginated.
    Use mod_digestforum_external::get_digestforum_discussions instead.
  * External function mod_digestforum_external::add_discussion_post() has a new 'messageformat' param to be able to handle other formats different from FORMAT_HTML (that continues being the default one). Also a new 'topreferredformat' option enables the automatic conversion between any format and the preferred format (given the editor preference) before contents are saved.

=== 3.6 ===

  * digestforum_print_post should be surrounded with calls to digestforum_print_post_start and digestforum_print_post_end to create the proper HTML structure for the post.

=== 3.4 ===
  * External function get_digestforum_discussion_posts now returns an additional field "ratinginfo" containing rating information.

=== 3.3 ===
  * External function get_digestforums_by_courses now returns and additional field "istracked" that indicates if the user
   is tracking the related digestforum.
  * The legacy digestforum.js file has been removed, this includes the js functions:
    digestforum_produce_subscribe_link, digestforum_produce_tracking_link, lockoptions_timetoitems,
    lockoptions_timefromitems, lockoptions, lockoption, unlockoption
  * External function can_add_discussion now returns two additional fields:
   "canpindiscussions" that indicates if the user can add pinned discussions.
   "cancreateattachment" that indicates if the user can add attachments to the discussion.

=== 3.1 ===
 * The inteface to digestforum_get_email_message_id() has changed and no longer needs the $host argument.

=== 3.0 ===
 * External function get_digestforums_by_courses now returns and additional field "cancreatediscussions" that indicates if the user
   can create discussions in the digestforum.

   This parameter can override the automatically calculated current group.
 * New constant DFORUM_POSTS_ALL_USER_GROUPS, to be used as parameter in functions where we'd need to retrieve all the user posts.

=== 2.6 ===

* The file post_form.php should not be included, the class it contained has
  been moved so that it can benefit from autoloading.
* The function digestforum_shorten_post() has been deprecated. It was doing a poor
  job of shortening digestforum post text and the shorten_text() function does a
  much better job.
* The constant DFORUM_TRACKING_ON has been deprecated and replaced by
  DFORUM_TRACKING_FORCED. The value between them is maintained, so they are
  interchangeable, but code should migrate to the new name.

=== 2.5 ===

The function digestforum_check_throttling has been changed so that a warning object is returned when a user has reached the 'Post threshold for warning' or
'Post threshold for blocking' setting, rather than echoing this on screen. This allows the warning to be moved inside the post form as it can be added
as a HTML element, where it is more noticeable. False is returned if there is no need to warn, or restrict the user from posting - see MDL-39182.

=== 2.3.5, 2.4.2 ===

* mod/digestforum:allowforcesubscribe capability will be forcefully assigned to frontpage role, as it was mistakenly missed off
when the capability was initially created. If you don't want users with frontpage role to get digestforum (with forcesubscribe) emails,
then please remove this capability for frontpage role.
